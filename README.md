## 把机制变成可以看见的过程

敲响铜钟，看信息逐站传递；点亮一个词，观察它与上下文的联系。沿着苏格拉底式的追问，在手稿、器物与金墨之间，探索 AI 如何理解语言。

**当前为 v0.1 原型**：开放外星人身份，包含 Attention、QKV 与 Transformer 的四段课程，以及一道选择题和总结。玩法与声音仍在打磨，更多身份和论文路线尚未开放。

## 创作手记

这是一次与 Codex 共同完成的 Vibe Coding 尝试。我们花了很多时间寻找学院的美术语言，也学着从无尽的细节中停下来，先让作品与读者见面。

接下来，让真实反馈推动体验，也继续探索更可靠的人机协作与 AI 迭代方式。
